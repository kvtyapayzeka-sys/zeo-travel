### 3.7 Core Web Vitals Hedefleri

| Metrik | Hedef | Stratejiler |
|--------|-------|-------------|
| **LCP (Largest Contentful Paint)** | < 2.5s | - Hero image'i optimize et<br>- SSR/SSG kullan<br>- CDN kullan<br>- Preload critical resources |
| **FID (First Input Delay)** | < 100ms | - JavaScript bundle'ı küçült<br>- Code splitting<br>- Lazy load non-critical JS |
| **CLS (Cumulative Layout Shift)** | < 0.1 | - Image/video için width/height belirt<br>- Font display: swap<br>- Dinamik içerik için placeholder |
| **INP (Interaction to Next Paint)** | < 200ms | - Debounce/throttle kullan<br>- Web Workers ile heavy tasks<br>- Optimize event handlers |
| **TTFB (Time to First Byte)** | < 800ms | - Server-side caching<br>- CDN kullan<br>- Database query optimization |
